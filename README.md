# Ashwin SDV Portfolio Website

Static GitHub Pages-ready portfolio template for an Automotive Controls & Software Systems Engineer.

## Files

- `index.html` — homepage
- `assets/styles.css` — styling
- `assets/app.js` — small mobile-menu script
- `projects/*.html` — detailed project case-study pages

## How to publish on GitHub Pages

1. Replace your existing repository files with these files, or create a new repo.
2. Commit and push to GitHub.
3. Go to **Settings → Pages**.
4. Choose branch: `main` and folder: `/root`.
5. Save and open the generated GitHub Pages link.

## What to customize next

- Replace placeholder GitHub repo links with your actual project repos.
- Replace LinkedIn placeholder with your exact LinkedIn URL.
- Add screenshots/GIFs under `assets/` and reference them inside project pages.
- Add your resume PDF and link it in the hero section.
- Add real sample data and downloadable reports to each project repo.
