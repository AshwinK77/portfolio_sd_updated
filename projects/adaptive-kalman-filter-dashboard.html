Adaptive Kalman Filter Dashboard

A dashboard for tuning process/measurement noise, comparing fixed and adaptive filters, and visualizing consistency diagnostics such as NIS and 3σ bounds.

1. Engineering Problem

State-estimation work is difficult for recruiters to understand unless the filter behavior is visual. This dashboard makes Q/R tuning, innovation consistency, and estimation confidence easy to see.

Portfolio goal: Make the project read like an engineering tool used for integration, validation, debugging, or controls development — not just a classroom exercise.

2. System Architecture

Vehicle Sensor Data / Simulated Truth ↓ Measurement Model + Vehicle Model ↓ Fixed KF / Adaptive KF / EKF ↓ State Estimates + Innovations + Covariance ↓ RMSE, NIS, 3σ, Overconfidence Diagnostics

3. Core Features

Tool Features

  • Load yaw-rate, lateral acceleration, steering, speed, and sideslip data
  • Tune Q and R interactively
  • Compare measured vs estimated vs ground truth
  • Show innovation and residual plots
  • Evaluate NIS pass rate and 3σ consistency

Validation Metrics

  • RMSE reduction
  • NIS pass rate
  • Innovation whiteness indicator
  • 3σ containment
  • Runtime per dataset
