Vehicle Controls Test Automation Dashboard

1. Engineering Problem

Track and high-speed controls testing generates large telemetry datasets across torque vectoring, ABS, traction control, and torque-differential features. The engineering challenge is to retrieve only the signals relevant to each test window, automate feature-specific analysis, preserve traceability to the testcase/test plan, and expose regression status by vehicle variant and test cycle.

Portfolio goal: Make the project read like an engineering tool used for integration, validation, debugging, or controls development — not just a classroom exercise.

2. System Architecture

Test Timestamps + Vehicle / Variant Metadata ↓ Databricks / Cloud Telemetry Query ↓ Relevant Signal Extraction → CSV Dataset ↓ Feature Router → TV / ABS / TCS / Torque-Diff Post-Processing ↓ Metrics + Pass/Fail + Failure Classification ↓ Testcase / Test-Plan Writeback + Regression Dashboard

3. Core Features

Tool Features

  • Read test timestamps, vehicle, variant, build, and test-cycle metadata
  • Query Databricks/cloud telemetry for only the signals required by the selected controls feature
  • Export the synchronized test window as CSV and route it to the appropriate Python post-processing script
  • Write calculated metrics, pass/fail results, and evidence back to the testcase/test plan
  • Track regression status across variants and test cycles with failure type and priority

Validation Metrics

  • Pass rate by feature, variant, build, and test cycle
  • Automated vs completed post-processing count
  • Failure type distribution and P1/P2/P3 priority
  • Regression trend for Torque Vectoring, ABS, TCS, and Torque Differential
  • Traceability from cloud dataset to testcase result and evidence
