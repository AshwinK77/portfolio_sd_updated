1. Engineering Problem

Controls portfolios often show static plots. This project turns the controls model into an interactive tool that demonstrates vehicle dynamics intuition, controller tuning, and validation thinking.

Portfolio goal: Make the project read like an engineering tool used for integration, validation, debugging, or controls development — not just a classroom exercise.

2. System Architecture

Vehicle Parameters + Maneuver Input ↓ 2-DOF Bicycle Model / Optional 7-DOF Extension ↓ Baseline Response LQR/PID/DYC Controller ↓ ↓ Yaw Rate, Sideslip, Ay Corrective Yaw Moment / Torque Allocation

3. Core Features

Tool Features

  • Select step steer, sine-with-dwell, fishhook, or double lane change
  • Tune speed, mass, wheelbase, cornering stiffness, and controller gains
  • Compare desired vs actual yaw rate
  • Plot sideslip angle and lateral acceleration
  • Export simulation data and figures

Validation Metrics

  • Yaw-rate tracking error
  • Peak sideslip angle
  • Settling time
  • Controller effort
  • Stability margin comparison
