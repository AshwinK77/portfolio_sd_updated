MoTeC C1812 HMI + CAN Diagnostics

A driver-focused HMI concept that visualizes real-time vehicle diagnostics through CAN signals and supports multi-page navigation during integration and regression testing.

1. Engineering Problem

During vehicle integration, drivers and engineers need immediate visibility into system states, faults, and key parameters without digging through raw logs. A structured HMI improves situational awareness and test execution.

Portfolio goal: Make the project read like an engineering tool used for integration, validation, debugging, or controls development — not just a classroom exercise.

2. System Architecture

Vehicle ECUs / Raptor ECU / CAN Bus ↓ CAN Signal Mapping + Display Creator ↓ MoTeC C1812 Pages ↓ Driver Alerts · Diagnostics · State Visualization · Test Support

3. Core Features

Tool Features

  • CAN-based diagnostic signal visualization
  • Multi-page display layout for system states and faults
  • Steering-wheel button navigation
  • Driver-focused alerts and status messages
  • Useful during regression testing and integration debugging

Validation Metrics

  • Signal coverage by subsystem
  • Page navigation latency
  • Fault visibility during tests
  • Regression support use cases
  • Validated display states
